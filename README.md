# Parcel Picker
A driver game for picking up parcels, built with vanilla JavaScript only.

## Usage
1. Install the dependency:
   ```bash
   npm install @igor-j86/parcel-picker
   ```
2. Import the library and start the game:
   ```javascript
   import parcelPicker from '@igor-j86/parcel-picker';
   
   parcelPicker()
    ```

## Tech stack
- TypeScript
- Vite
